# Project color

The tab bar painted in the shown project's own color, and every space and agent in the
sidebar marked with its project's color, so each space is recognisable at a glance, like
per-project VS Code title bars.

![Project color](preview.png)

## What you see

- Tab bar (42px, Herdr's own): its background, and the background of inactive tabs and of the
  Files/Changes buttons, is the shown project's color; its bottom border too. The active tab
  keeps Herdr's raised card and colors. On the color, inactive tab text and tinted icons are
  black or white at 85% (WCAG luminance, threshold 0.179) and the `+` and window buttons at 65%.
- Spaces sidebar: each space's 18px letter tile is filled with its project color.
- Agents panel: a 6x16px rounded stripe in the agent's space color at the left of each row
  (6x14px on the narrow rail), and a 7px dot before each space header when sorted by space.
- The OS window title becomes `<space name> - Herdr`.

## How it behaves

- Switching spaces repaints the tab bar at once (colors cached per machine and folder).
- The shown space's color is read again every 30 s.
- Until a space's lookup finishes it shows Herdr's automatic color (theme-name pick).
- Hovers and clicks on the tab bar are Herdr's, unchanged.

## Built from

- Layout: a clone of `main` (`layout.clone {name: "main", as: "colors"}`). First child of the
  `work` column: `{ "id": "project-color", "type": "block", "size": { "px": 0 }, "content": { "mod": "project-color", "props": { "bar": false } } }`.
  The `tabs` block's mod is `project-color-tabs`, the `agents` block's `project-color-agents`.
- `mods/project-color/main.js`: for every space, `panes()` for its first terminal's `cwd`
  (else `space.folder`), `exec("git", ["-C", cwd, "rev-parse", "--show-toplevel"], { on: space.machine })`,
  `readTextFile("<root>/.vscode/settings.json", { on: space.machine })`; `setWindowTitle`.
  With `props.bar !== false` it draws a 26px bar in the color instead (the first version).
- Every space's color is written to shared `space.colors` (space id to `#rrggbb`), which the
  shipped `spaces` and `picker` mods already draw tiles from. Shared `project-color.written`
  remembers what this mod wrote, so a person's own hex pick is never overwritten; Herdr's
  automatic theme-name picks are.
- `mods/project-color-tabs` and `mods/project-color-agents`: generated by
  `tools/build-clones.mjs` from the shipped `tabs` and `agents` mods with regex-anchored
  patches that read `space.colors`.
- `mods/project-color/color.js`: JSONC stripping, `titleBar.activeBackground` then
  `peacock.color`, FNV-1a hash of the repo name into a 10-color palette, contrast, the merge.

## Watch out

- `mod.json` `place: "top"` does not dock into the shipped `main` layout; blocks must be added by hand to a clone.
- A junction or symlink into `mods/` is not picked up; copy the folder.
- Shipped mods' files have CRLF line endings on Windows; normalise before matching.
- A Herdr update changes the shipped mods, not the clones: rerun the build script. It
  refuses to write if any anchor no longer matches exactly once.
- The tabs clone still loads its window-button icons from `mods/tabs/`.
- A space on a stopped machine (dev container) can't be read; it falls back to the hash color.
- Colors with alpha (`#rrggbbaa`) drop the alpha; `#rgb` is expanded.

## Done when

- `herdr-app check` passes for all three mods.
- Two spaces in repos with different `titleBar.activeBackground` show those two tab bar colors.
- A space on a dev container machine shows the color from the settings file inside the container.
- A repo without settings gets the same color every time.
- Switching spaces changes the window title (proves the 0px block runs).
- Space tiles and agent stripes match the tab bar's color for the same space.
