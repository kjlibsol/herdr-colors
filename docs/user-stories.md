# User stories

High-level user stories for herdr-colors, reverse engineered from what the mods do today.

## 1. See at a glance which project I'm in

As someone working in many Herdr spaces at once,
I want each project to have its own color across the window (tab bar, spaces, machines, agents),
so that I always know which project I'm looking at and don't type into the wrong one.

## 2. Pick a project's color where I see it

As a Herdr user,
I want to right-click a space, machine or agent and choose its color,
so that I can set or change a project's color without editing files.

## 3. Keep a color with the project, or just for me

As a developer who shares repos with others,
I want to save a project's color in the repo or only on my own computer,
so that my team sees the same color, or I can have my own without touching the repo.

## 4. Every project gets a color automatically

As a Herdr user who hasn't set any colors,
I want every project to get a distinct color on its own, and keep it,
so that colors help me from day one and don't change under me.

## 5. Reuse the colors I already set in VS Code

As someone who already colors projects in VS Code,
I want Herdr to pick up those colors,
so that a project looks the same in both tools without setting it twice.

## 6. Dev containers carry their project's color

As a developer working in dev containers and on other machines,
I want a dev container and its spaces to show their project's color, even while it is stopped, and every other machine a color of its own,
so that I can tell them apart as easily as local projects.

## 7. Changes show up quickly without slowing Herdr down

As a Herdr user,
I want a color change to show up right away, without the mod constantly running commands in the background,
so that Herdr stays fast and my machines stay quiet.

## 8. Safe to install and nothing written behind my back

As someone installing a mod from the internet,
I want to know what it runs and writes, and have it only change files when I ask it to,
so that I can trust it with my repos and my Herdr setup.

## 9. Survives Herdr updates

As a Herdr user,
I want to rebuild the mod's parts easily after a Herdr update, be told clearly if something no longer fits, and get back to Herdr's own layout in one step,
so that an update never leaves me stuck.

## 10. Know which project and which color I'm changing

As a Herdr user picking a color,
I want the picker to show which repo the color applies to, how many spaces share it, and where the current color comes from,
so that I change the right thing and understand why a color is what it is.

## 11. Back out cleanly

As someone trying the mod,
I want to switch back to Herdr's own layout at any time and uninstall without leftovers I don't know about,
so that trying it costs nothing.
